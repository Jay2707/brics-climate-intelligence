# BRICS Climate Intelligence — Design Direction

## Three Possible Directions

### 1. Monsoon Signal Room
**Very Brief Intro:** An editorial command-center that turns invisible atmospheric movement into a calm, living topographic story. It pairs scientific discipline with civic optimism.

**Probability:** 0.07

### 2. Terra Ledger
**Very Brief Intro:** A warm, archival environmental journal where satellite intelligence is presented with documentary photography, dense annotation, and restrained cartographic color.

**Probability:** 0.04

### 3. Aurora Mesh
**Very Brief Intro:** A midnight data observatory that visualizes shared climate infrastructure as a luminous planetary mesh. It feels decisive, precise, and future-facing.

**Probability:** 0.09

## Chosen Direction — Monsoon Signal Room

### Design Movement
The interface draws on **contemporary cartographic editorial design**: a public-interest data newsroom crossed with an atmospheric research lab. It avoids generic dashboard chrome by making each surface feel like a page from a field atlas, alive with sensor traces and weather formations.

### Core Principles
1. **Atmosphere is information.** Pollution pathways, pressure fields, and confidence levels are visible as layered spatial phenomena rather than detached widgets.
2. **Civic data feels human.** The platform balances satellite intelligence with local eyewitness reports, giving both equal visual legitimacy.
3. **Urgency without alarmism.** Critical states use measured contrast and precise language, never visual noise or panic.
4. **Shared context before action.** Country-specific work remains legible inside the wider BRICS corridor, encouraging coordinated action rather than isolated monitoring.

### Color Philosophy
The foundation is deep **monsoon ink** (blue-black) for the sensing layer: it creates a quiet, credible field for satellite traces and luminous data. Clay, pollen yellow, and oxidized copper mark increasing environmental risk, while river-mint is reserved for verified and healthy conditions. The near-paper base and misted panels reference scientific field notebooks; color is used as a semantic signal, not decoration.

### Layout Paradigm
The primary experience is a **split field atlas** rather than a conventional centered dashboard. A narrow navigation rail anchors the left edge; a dominant, irregular map field holds the atmospheric story; analysis panels overlap the field as movable research slips. On small screens, this compresses into a narrative stack where the map remains the first visual anchor.

### Signature Elements
1. **Contour-line weather fields:** thin flowing paths and translucent plumes move through the map and section backgrounds.
2. **Field-note cards:** lightly textured, offset cards with tiny metadata labels and confident, editorial headlines.
3. **Signal pins:** ringed map markers that show a source type, severity, and live pulse only when meaningful.

### Interaction Philosophy
Interactions should feel like examining an instrument panel: hover states reveal source provenance, map controls update the active story, and buttons use direct action language. Rich action (opening an alert, submitting a report) has a clear visual consequence and concise confirmation; passive motion stays restrained.

### Animation
Atmospheric layers drift on slow 14–24 second loops, only when motion is allowed. Data cards enter with a 40–70ms cascading delay using opacity and a small vertical transform. Controls respond in 120–180ms with a firm ease-out; map pins subtly breathe at critical levels, but no element uses a continuous flashy glow. All nonessential movement is disabled under `prefers-reduced-motion`.

### Typography System
**DM Sans** handles navigation, data labels, and UI body copy for technical clarity. **DM Serif Display** carries the editorial assertions and numeric callouts, with high contrast that counterbalances the dense data field. Display headlines use tight tracking and sentence case; utility labels use uppercase, generous letterspacing, and small sizes.

### Brand Essence
**A shared intelligence layer for BRICS cities to see pollution early, act locally, and coordinate across borders.**

Personality: **observant, civic, resolute.**

### Brand Voice
The voice is clear, evidence-led, and action-oriented. Headlines name the atmospheric event; CTAs describe the next operational move. Avoid abstract innovation claims and generic startup phrases.

Example lines:

> “A smoke corridor is forming. See where it travels next.”

> “Verify this signal and brief the corridor partners.”

### Wordmark & Logo
The mark is an **interlocking five-river knot**: five tapered paths converge into a single circular sensing point, representing member nations, shared air, and federated data. It has no embedded type, works in a single color, and is used beside a custom set wordmark with a small contour-line flourish.

### Signature Brand Color
**Monsoon Ink — #0B2535.** This near-black blue anchors every high-trust surface, making the platform recognizably BRICS Climate Intelligence even without its wordmark.

## Style Decisions

- The landing page behaves like a live operational briefing, not a generic product brochure.
- Use thin contour lines, paper-like panels, satellite-style color overlays, and calibrated severity accents.
- All labels and sample values must clearly be presented as **demonstration data** until live sources are connected.
- Reserve monsoon-ink glass for active sensing and operational controls; civic evidence should surface as misted near-paper research slips with provenance stamps.
- Repeat the five-river geometry in section marks, field notes, and signal details so the identity persists away from the wordmark.
- Pair every satellite or forecast story with an equally legible local-evidence cue, verification state, or source trace.
